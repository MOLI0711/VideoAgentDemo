# vedioagent 视频知识工作台

Vue 3 + TypeScript + Vite 的中文工作台，与项目 Go API 同源部署。开发代理将 `/v1` 转发到 `http://127.0.0.1:8080`，前端没有静态答案或自动成功的演示分支。

## 启动与检查

需要 Node.js 22.12+；本轮使用 Node.js 24.21.0、npm 11.19.0 验证。依赖固定在 `package.json` 和 `package-lock.json`，统一使用 npm。

```bash
cd web
npm ci
npm run dev
```

浏览器访问 Vite 输出的本地地址，默认 `http://127.0.0.1:5173`。先按仓库根目录说明启动 API 并迁移数据库。直接打开即可进入访客工作台，无须初始化账号或填写密码。

```bash
npm run typecheck
npm test
npm run build
npm run format:check
```

`npm test` 测试访客会话恢复、CSRF 与失效请求不重放、SSE 快照/游标/去重/终态、分片规划与传输失败、文件匹配、毫秒定位及幂等键。测试使用明确的 fake transport，不调用云模型，也不代表完整系统或真实效果已验证。`npm run build` 生成 `dist/`，部署时由反向代理托管静态文件并转发 `/v1`；Vite `preview` 只用于检查静态构建。

## 使用流程

1. 直接打开工作台。先从 `/v1/auth/session` 恢复会话，401 时自动通过 `POST /v1/auth/guest` 建立访客空间，并获得已发布的“视频助手”。有效的旧 Cookie 继续访问原数据。CSRF token 仅保留在内存；会话失效自动恢复，失败时显示重新连接入口。清除站点数据或访客会话到期后无法恢复访问原空间。
2. 在 Agent 工作室创建 Agent，填写服务器允许的模型配置引用，保存草稿，再发布。已发布版本不可编辑，可复制为新草稿。
3. 上传本地 MP4。文件上限 2 GiB，按服务端指定大小（默认 8 MiB）分片，最多并行 3 片。任务页展示真实后端状态，媒体字节上传进度与处理进度分别呈现。
4. 可暂停上传，重新进入资料库并选择原文件继续。浏览器仅保存当前用户范围内的上传会话和文件指纹；实际分片以服务端 `ListParts` 为准。指纹是首尾采样加元数据，用于防止误选文件，并非文件完整性证明。完成合并前再次核验所有分片。
5. 处理完成后进入视频工作台。点击字幕、章节或回答证据跳转到对应毫秒；截图通过有权限校验的资产 API 获取。播放链接过期时点击“刷新播放链接”。
6. 选择已发布 Agent 版本并提问。会话固定视频内容和 Agent 版本；后续追问沿用该版本。可用 `Ctrl/⌘ + Enter` 提交问题。
7. 问答先读取持久快照，再从 `after_seq` 订阅后续事件。重复事件被丢弃，重试 attempt 清空旧过程记录，终态事件触发最终快照读取。刷新、暂时断线或离开页面不取消后台任务；取消必须显式点击。
8. 当前用户最后打开的会话和运行 ID 保存在浏览器本地元数据中，刷新页面可恢复。会话内容与回答本身来自服务端。

`/v1/meta` 指示模型或 ASR 使用 `mock` 时，顶部显示“合成测试模式”，输出只用于功能联调。

## 代码边界

- `src/api/`：类型、Cookie/CSRF 请求、错误与幂等提交、SSE 快照恢复。
- `src/components/`：上传、任务状态、视频工作台、Agent 版本、运行与证据。
- `src/lib/`：分片和时间转换等独立逻辑及测试。
- `src/stores/`：运行事件游标、去重与 attempt 处理。
- `src/App.vue`：访客连接状态、资料库与主导航；`src/style.css`：响应式样式。

前端不渲染模型任意 HTML，不根据模型文本拼接资产 URL，不让模型时间字符串决定跳转位置。引用使用后端校验过的 `evidence` ID、实际时间和资产 ID。所有服务端资源访问仍须检查当前用户归属。

## 联调注意

- `GET` 列表返回 `{ "items": [] }`；ID 为字符串，时间为毫秒。
- Agent 草稿字段为 `prompt/model_ref/tools/budgets`；发布后才可创建会话。
- `POST /sessions` 返回 `id/video_id/content_version/agent_version_id`；`POST /runs` 返回 `run_id/job_id/status`。
- `GET /runs/:id` 返回状态、`latest_event_seq` 和可选 `result`；正文只从 `result.claims` 渲染，引用从 `result.evidence` 读取。
- 409 按业务错误码显示；结果不明的上传创建与问答提交，在当前页面重试时复用幂等键。会话和 Agent 创建接口尚不使用幂等键；不要盲目重复提交。401/CSRF 拒绝会恢复 Cookie/CSRF，但不会自动重放写操作；用户身份变化时清空旧工作台并载入当前空间。
- 对象存储必须允许浏览器源的 PUT/CORS 并暴露 ETag；签名 URL 的 host 不可由前端替换。分片超时为 120 秒，可重新签名后续传。
- SSE 需要反向代理关闭缓冲，允许长连接；不得把长期凭据写入查询参数。
- 真实云调用、S3 CORS 与 Range、故障恢复需要完整服务环境联调，单元测试和静态构建不替代这些检查。
